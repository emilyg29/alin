# MASKER

Secure Media Hiding System
Submitted by: Emily Groisman
Version 1.0

## תיאור המערכת

MASKER היא מערכת שרת-לקוח המאפשרת למשתמשים להסתיר קובץ תמונה בתוך תמונה אחרת ולפענח מידע מוסתר. המערכת כוללת הרשמה והתחברות, הצפנת תקשורת, מסד נתונים ומסך ניהול לשרת.

## דרישות

כדי להפעיל את הפרויקט נדרשים:

- Python 3
- MySQL
- mysql-connector-python
- pycryptodome
- Pillow
- pygame

פקודת התקנה:

pip install mysql-connector-python pycryptodome Pillow pygame

## הפעלת המערכת

יש לפתוח Terminal בתיקיית alin.

תחילה מפעילים את השרת:

python cyber_server.py

לאחר מכן פותחים Terminal נוסף ומפעילים את הלקוח:

python cyber_client.py

## שימוש במערכת

1. משתמש חדש חייב ללחוץ Register ולהירשם.
2. לאחר הרשמה תקינה ניתן ללחוץ Login.
3. לאחר ההתחברות ניתן לבחור:
   - Hide Data – הסתרת תמונה בתוך תמונה.
   - Decode Data – חילוץ מידע מוסתר.
   - Logout – יציאה מהמערכת.

## אבטחה

הסיסמאות אינן נשמרות כטקסט גלוי. הן נשמרות באמצעות PBKDF2-HMAC-SHA256 עם salt אקראי. שם המשתמש נשמר כ-SHA-256 hash. הודעות וקבצים מועברים באמצעות הצפנת AES-GCM עם מפתח AES-256 אישי הנמצא בקובץ personal.key.

## נתיבים

במסד הנתונים נשמרים שמות קבצים יחסיים בלבד ולא נתיבים אישיים כגון C:\Users\.... כך ניתן להעביר את הפרויקט למחשב אחר.

## מסך השרת

מסך השרת מציג:

- לקוחות המחוברים כרגע.
- את כל הלקוחות הקיימים.
- מספר הקבצים שהועלו.
- מספר הקבצים שבהם נמצא מידע מוסתר.
- מספר הקבצים שפוענחו.

## קבצים מרכזיים

encrypt.py – הצפנה ופענוח.

personal.key – מפתח ההצפנה האישי.
