MASKER – CHANGES SUMMARY
Submitted by: Emily Groisman

1. אילו בעיות תוקנו

תוקנה הצגת המשתמשים המחוברים, כך שהמערכת אינה מציגה עוד כל משתמש שהתחבר בעבר כאילו הוא עדיין מחובר. בוצעה הפרדה בין Register לבין Login, חוזק השימוש ב-hash, הורחבה טבלת הלקוחות בסטטיסטיקות קבצים, תוקנו נתיבי קבצים והורחבה ההצפנה להעברת קבצים. בנוסף שופר מסך השרת ונוספו Splash Screen ואודיו אישיים.

2. כיצד הבעיות תוקנו

מצב החיבור הנוכחי מנוהל במבנה connected_users בזיכרון. משתמש נוסף אליו לאחר Login תקין ונמחק ממנו בעת Logout, סגירת החיבור או שגיאה. היסטוריית ההתחברויות נשמרת בנפרד בטבלת login_history. פעולות Register ו-Login הופרדו ונוספו הודעות שגיאה ברורות. מוני הקבצים מתעדכנים בטבלת clients לאחר פעולות Hide ו-Decode.

3. אילו הרחבות נוספו

נוספה טבלת login_history, נוספו סטטיסטיקות לכל לקוח, שופר מסך השרת ונוספו חלון פרטי לקוח וחלון להצגת היסטוריית קובצי המדיה שלו. בנוסף נוספו Splash Screen אישי ואודיו אישי.

4. כיצד טופלה הצפנת הקבצים

הודעות טקסט ותוכן בינארי נשלחים באמצעות המחלקה Encryption. ההצפנה מבוצעת באמצעות AES-GCM, המספק סודיות ובדיקת שלמות. נוצר מפתח AES-256 אישי חדש בקובץ personal.key. המפתח נבדק באמצעות הצפנה ופענוח של הודעת בדיקה, והתקבלה התוצאה TEST PASSED: True.

5. כיצד נפתרה בעיית המשתמשים המחוברים

רשימת Connected Clients נבנית רק מתוך connected_users, המכיל את החיבורים הפעילים כרגע. כאשר לקוח מתנתק, הרשומה שלו נמחקת בתוך finally ולכן הוא נעלם מרשימת המחוברים. הלקוח נשאר בטבלת clients וממשיך להופיע ברשימת All Clients, וכך נשמרת הפרדה בין מצב נוכחי לבין היסטוריה.

6. כיצד טופלו הנתיבים במסד הנתונים

במסד הנתונים נשמרים שמות קבצים יחסיים בלבד, לדוגמה hidden_1_20260913181213.jpg, ולא נתיבים אישיים כמו C:\Users\.... הנתיבים נבדקו גם בתוך טבלת decrypted_media ולא רק בקוד. בזמן העבודה הקוד מחבר את שם הקובץ לתיקיית הפרויקט הנוכחית, ולכן המערכת יכולה לעבור למחשב אחר.

7. מהו ה-Splash Screen שנוסף

נוסף מסך פתיחה בעיצוב אישי הכולל את הכותרת Image hiding system, שם המגישה Emily Groisman והגרסה Version 1.0. המסך מוצג לפני פתיחת מסך השרת.

8. מהו ה-Audio שנוסף

נוסף קובץ שמע אישי בשם emily_audio.mp3. הקובץ נטען באמצעות pygame ומושמע בעת הצגת מסך הפתיחה. הנתיב אליו נבנה יחסית לתיקיית הפרויקט.

9. מהו הרכיב האישי

הרכיב האישי שהוספתי הוא אפשרות Show password במסך ההרשמה וההתחברות. מתחת לשדה הסיסמה נוסף checkbox המאפשר למשתמש לבחור אם להציג את הסיסמה כטקסט רגיל או להסתיר אותה באמצעות כוכביות.

בחרתי ברכיב זה כדי לשפר את חוויית המשתמש ולאפשר לו לבדוק שהקליד את הסיסמה בצורה נכונה, במיוחד בסיסמאות מורכבות. האתגר היה לשנות את מאפיין show של שדה הסיסמה באופן מיידי, בלי למחוק את הטקסט שהמשתמש כבר הקליד ובלי לפגוע בפעולות Register ו-Login.
